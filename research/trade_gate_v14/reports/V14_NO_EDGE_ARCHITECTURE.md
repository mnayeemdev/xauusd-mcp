## Why a gate
V13 found no demonstrated edge in any existing strategy (EDGE_NOT_DEMONSTRATED; CORRECTION_CANDIDATE = NONE). V14 therefore adds no edge research. It defines how MCP behaves when no edge is demonstrated: WAIT is a valid, preferred state, and the system may produce zero trades.

## Where the gate sits
```
MARKET DATA (confirmed 5m bars)
  → FROZEN V8 ENGINE (unchanged): pattern / setup / trigger per strategy, direction, location, structural SL, RR, quality
  → TRADE GATE (V14): a deterministic map of the engine's own result and the existing safety limits to one state
  → TRADE_ELIGIBLE or WAIT_* / RISK_REJECTED  (execution authority: NONE)
```

The gate is NOT an edge generator.
- It never creates an entry the engine did not generate.
- It never picks a direction.
- It never changes an entry, SL or RR.
- It never increases risk after a loss, and never uses Capital Harvest.

## Behaviour the evidence supports today (PRIMARY: RISK_PERCENTAGE = UNRESOLVED)
- **No trades.** Over 99,381 decision bars (DEV + HOLD), the gate returns **TRADE_ELIGIBLE = 0**.
- **Every valid entry is risk-rejected.** All 11,411 valid entries generated by the engine are VALID_ENTRY + RISK_REJECTED (RISK_PERCENTAGE_UNRESOLVED), because no risk percentage is approved.
- **Every other bar has a deterministic WAIT reason.**
- **Zero trades is the correct output, not an error.**

## Status

- **Failure conditions:** none fired: 0 invariant violations, deterministic, restart-equal, no lookahead, exact V11 parity.
